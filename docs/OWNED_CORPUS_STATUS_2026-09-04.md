## 인벤토리 기준

공고 상세 HTML의 공급대상 표와 공급금액 표를 교차검증해 다음 exact key를 만듭니다.

```text
(complex_id, unit_type_id, normalized_unit_type_name, sale_price_manwon,
 source_sha256, extractor_version)
```

공고번호만 같아도 PDF SHA-256, 주택형, 분양가, extractor 버전 중 하나가 다르면
기존 검수 상태를 사용하지 않습니다. 원본 PDF와 실행 결과는 Git 저장소에 포함하지
않습니다.

## 신규 운영 공고 처리

1. Backend가 Crawler에서 받은 fresh pre-signed PDF URL과 exact target을 AI에 전달합니다.
2. AI는 URL을 저장하지 않고 PDF SHA-256, 페이지 수, target, 자동결과를 캡처합니다.
3. 원문·주택형·추가비용 범위를 대조하고 필요한 오류를 교정합니다.
4. 실제 검수자가 승인한 exact tuple만 `REVIEWED` allowlist에 추가합니다.

원본이 한 번도 AI 서버에 전달되지 않았거나 exact key가 다르면 `AUTO_EXTRACTED`가
나오는 것이 정상입니다. PDF가 없는 공고는 `AI_SERVER_FAILED`로 가장하지 않고
원본 미제공/분석 불가 HOLD로 구분해야 합니다.
