## 사용 규칙

- 세 건 모두 JSON fixture로 관리하고 스키마·검증·후보 페이지 회귀 테스트에 사용합니다.

- 현재 키 없이 실행하는 fixture 테스트 통과를 AI 정확도라고 부르지 않습니다.
